# Online Food Delivery System

This is a simple project for an Online Food Delivery System. It shows how customers can browse the menu, place orders, and track their orders. It was done using JavaScript and some UML diagrams.

---

## Problem Domain
The Online Food Delivery System helps customers to:
1. See the food menu.
2. Order food.
3. Track their orders easily.

This project is for learning how to design systems using object-oriented programming and UML diagrams.

---

## Features
1. **Add Food Items**: Add new food items to the menu.
2. **Register Customers**: Customers can register to use the system.
3. **Place Orders**: Customers can choose food from the menu and place an order.
4. **Track Orders**: Customers can check the status of their orders.
